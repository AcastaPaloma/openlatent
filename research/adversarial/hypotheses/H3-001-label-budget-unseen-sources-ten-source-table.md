# H3-001: The F3 label-budget break-even (about 10% of production labels) survives UNSEEN SOURCES and an unseen MICROSCOPE MODEL on the 10-source JUMP table, with 9 held-out sources as the unit

- Focus: JUMP label budget (programme-1 F line, generalisation) | Kind: replication / generalisation of the only learned-over-floor result | GPU-h: 6 reduced (5 folds) / 11 full (9 folds + 2 microscope folds) | Prior: 0.55
- Depends on: F4 (pre-registered, F.md section 10: 5-source leave-source-out, "objects" view, 1/3/10/30/100% grid) for the adapter code and aggregator; the 10-source assembled table download (2.81 GB, CC0, `profiles_var_mad_int_featselect.parquet`, 737 features); steward check that the table carries the metadata needed. F4 deliberately did NOT run the 10-source table, so this does not duplicate it; it is the version with enough sources to carry an interval.

## Statement
F3 (3 compound splits, one source set) showed that a supervised SupCon MLP adapter beats the full inductive floor envelope (including the 100%-label LDA) once ~10% of production compounds are labelled (dU_H +0.027 to +0.032 vs envelope, margin 0.010). Every F3 evaluation had the sources in the adapter's training set. H3-001 states: when ALL wells of a source (and, in a second arm, all sources of one microscope model) are removed from every fit, the adapter still beats the envelope fitted without that source at f = 10% in >= 7 of 9 held-out sources, and the break-even budget f* (smallest f in {1, 3, 10, 30, 100}% with dU_H >= 0.010, compound and plate lower bounds > 0) is <= 30% in >= 7 of 9. The source-transfer penalty (dU_H in the leave-source-out fold minus dU_H in the random-compound protocol at the same f) is in [-0.02, 0].

## Mechanism
The adapter learns "same compound, different instrument" from cross-source positives. A source it has never seen adds an unknown instrument shift. Nine training sources (eight at test) span five microscope models, so the set of instruments the adapter has seen is richer than in the 5-source universe (4 training sources, 3 microscope models), and the invariance it learns should transfer. The leave-microscope-model-out arm is the hard version: the CV8000 block (sources 2, 5, 6, 10) is removed together, leaving Opera Phenix (1, 3, 9), CV7000 (7), ImageXpress (8), Operetta (11). The linear floors cannot exploit source count the same way because their capacity is fixed by d.

## Experiment (exact)
- Data: JUMP cpg0016 assembled COMPOUND v1.0, 10 sources, 115,720 production compounds, 112,426 present in >= 2 sources; held-out-source candidates are the nine sources with >= 30k eligible compounds (1, 2, 3, 5, 6, 8, 9, 10, 11; source 7 has 6,053 compounds and stays in training). Target2 plates may be absent from this table: regimes `a` and `c` of F3 are then not run (check; do not substitute). Regimes: b1, b3, b10, b30, b100 = nested random fractions of the training-side production compounds labelled (all wells in the training sources), md5-hash selection as F3.
- Splits: compound split salt s0 for H / V / T' as F; two further salts s1, s2 run on three of the nine folds only (budget) to size the compound-split component. Front end: the table's own preprocessing is transductive; for the held-out source the INT/feature-selection cannot be refit (the table is pre-built), so this is stated as a limitation and the PRIMARY claim is the comparison adapter vs floors, both on the same front end.
- Fold = hold out source k: every Fit set, floor, LDA and adapter is fitted without any well of k. Queries = wells of k from H compounds; positives = same compound in any other source; negatives = other compounds on the same plate; mean AP per compound (F2 `ap.py`, validated against copairs). Leakage: retrained 10-class source attackers (linear, MLP, kNN, LightGBM; plate-disjoint halves, cross-fit, includes the held-out source's wells at attacker-train time; chance 0.10), L_norm = (worst - 0.1)/(worst_raw - 0.1), plates as units.
- Microscope folds: hold out {2, 5, 6, 10} (CV8000) and, if budget allows, {1, 3, 9} (Opera Phenix).
- Adapter: F2/F3 SupCon MLP D -> 1024 -> 512 -> d, tau 0.1, AdamW 1e-3 cosine, 8,000 steps, d in {8, 64}, output dither r in {0, 0.5}; no adversary. Comparators: E_full = {raw, pca16/64, dpca16_r1/2/4, rp64, ldaP_{4,8,16,32} at 100% labels (PCA-256 then shrinkage-0.1 LDA on training-source production compounds), ldaM_f_8 (same labels as the adapter)}; V-selected matching as F3 (envelope arm = highest U_V with L_V <= L_V(adapter) + 0.05).
- Trained check (memorisation-calibrated, F3 8.5): loss ratio, effective rank >= d/4, and U_V(arm) - U_V(perm_f_d64) >= 0.010.
- Seeds vs test units: units are held-out compounds (U), plates (L) and SOURCES (the cluster for the headline: 9 folds). One adapter training seed per (fold, f, d); two label draws (nested subsets from two md5 salts) on the three double-salt folds. Seeds replicate training noise only; folds replicate the test source; compound split salts replicate the H set. Per-fold MDE80 is recomputed by the sign-flip method (F 2.3) and a fold counts only if MDE80 <= 0.005.
- Cross-fit: the source attackers are cross-fit over plate-disjoint halves (as F); there is no cross-fit of the adapter across compound splits beyond s0/s1/s2.
- Pooled statistic: per-fold dU_H with compound-bootstrap and plate-cluster 95% intervals; across folds a sign test (9/9 one-sided p = 0.002; 8/9 p = 0.02; 7/9 p = 0.09) and the median break-even.

## Prediction and falsifier
- Predicted: f* <= 30% in 7-9 of 9 folds (point guess 8); dU_H(b10 vs E_full) in [+0.015, +0.040] in >= 7 folds; dU_H(b100) >= +0.08 in all folds; the CV8000-block fold keeps f* <= 30% with dU_H(b100) >= +0.05; source-transfer penalty median -0.008 [-0.02, 0].
- FALSIFIED (the break-even does not generalise) if f* > 30% (or censored above 100%) in >= 3 of 9 folds, OR dU_H(b100) < +0.05 in the microscope-block fold, OR the median source-transfer penalty is < -0.03.
- Not decided by a pass: a pass is about this table and this adapter family; it does not make the result label-free.

## Cost / dependencies
6 GPU-h reduced = 5 folds (1, 3, 8, 9, 11) + the CV8000 block, ~0.9 h per fold; 11 full. Front-end download and metadata join are CPU/disk. Depends on F4 for the code path; start only after F4's aggregator has run once on real output (so the code is exercised).

## Prior
0.55. Reasons for: 3/3 splits at 10% in F3, +0.13 at 100% is 13x the margin, eight training sources carry more instrument variety than the 4 of F4. Reasons against: unseen-instrument shift is a different failure mode from unseen compound, the 10-source features are pre-selected on all wells (leak in the helpful direction for neither arm, but unquantified), and the 10%-label gain is only 2.7-3.2x the margin, so a modest penalty could erase it.

## Cheapest floor that could kill it
The 100%-label LDA (`ldaP_8` / `ldaP_16`) fitted without the held-out source, which is already in E_full; and the transductive per-source references (Harmony) as a descriptive upper context: if Harmony run on the held-out source alone matches the adapter, the "unseen source" advantage is a transductive one (see H3-004).
